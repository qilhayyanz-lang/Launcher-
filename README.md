# Glass Launcher
Launcher Android bergaya iOS (Jetpack Compose).

## Build
Push ke GitHub, buka tab **Actions → Build APK → Artifacts → GlassLauncher-apk**.

## Fitur v0.1
- Home grid + dock + jam, pager multi-halaman
- Efek glass (gradien + border kilau), blur wallpaper saat panel terbuka (Android 12+)
- Swipe naik: App Library + pencarian; swipe turun: pusat notifikasi
- Animasi buka aplikasi (zoom), animasi tekan pegas, tekan lama = info aplikasi

## Setelah install
Tekan Home → pilih Glass Launcher → Selalu. Untuk notifikasi: buka pusat notifikasi lalu aktifkan aksesnya.
